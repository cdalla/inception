<h1>INCEPTION</h1>
This project aims to broaden the knowledge of system administration through the use
of Docker technology. Virtualize several Docker images by creating them in a virtual machine.
This project involves setting up a small infrastructure composed of different services under specific rules.<br>
- A container for NGINX <br>
- A container for MariaDB<br>
- A container for Wordpress with php-fpm<br>
- Two volumes for Wordpress website files and database<br>
- A docker-network thats establishes the connection between the containers<br>
